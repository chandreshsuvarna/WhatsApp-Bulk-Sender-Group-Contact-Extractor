WA Bulk Sender + Contact Extractor  (merged, v5.0.0)

INSTALL
1. Unzip this folder.
2. Chrome > chrome://extensions > turn on Developer mode.
3. Load unpacked > select the folder "wa_bulk_sender_with_extractor".
   (If you had the old sender or extractor installed, REMOVE them first, or click reload.)
4. Open https://web.whatsapp.com/ in a tab and wait for chats to load.

USE
Click the extension icon -> the app opens in a tab with two sections:
 - Group Contact Extractor: Load groups > pick a group > Get members >
   Download CSV / Excel, or "Use these contacts in Bulk Sender".
 - Bulk Sender: paste/upload contacts, write message, optional attachment, Start.

NOTES
- Keep the WhatsApp Web tab open. Don't run the extractor's fallback mode while a campaign is running.
- Members whose numbers WhatsApp hides (LIDs) are skipped and counted.
- Everything runs locally. Only message people who agreed to receive messages.
