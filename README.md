## What is this?

A Chrome Extension to send personalized bulk WhatsApp messages automatically, without typing each message manually.

Built to solve a real problem for sending personlise information to 200+ people every month.

## What it does

- Sends bulk messages from Excel / CSV list
- Personalizes each message - `Hi {Name}, your payment of Rs. X is due` or Invitation.
- Adds delay between messages to avoid WhatsApp block
- Shows Success / Failed report after sending
- Works directly on WhatsApp Web - No API cost

## Tech Stack

- JavaScript
- Chrome Extension Manifest V3
- HTML / CSS

## How to Install

1. Download this repo / Clone it
2. Go to `chrome://extensions` in Chrome
3. Turn ON `Developer Mode` (top right)
4. Click `Load Unpacked` and select this folder
5. Extension will appear in Chrome toolbar

## How to Use

1. Prepare Excel with Name, Number, Message
2. Open WhatsApp Web and login
3. Open extension, upload list
4. Click Start - It will send one by one with delay

## Why I Built This

Manual sending to 200 members took 2 days. With this tool, same work takes 20 minutes.

## Disclaimer

Use responsibly. This tool is for sending messages to your own customers / contacts with their consent. Follow WhatsApp Terms.
